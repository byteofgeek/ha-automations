# Byte of Geek - Home Assistant Automations

Welcome to the **Byte of Geek Home Assistant Automations** repository!

This repository contains example Home Assistant automations featured in videos on my [Byte of Geek YouTube channel](https://www.youtube.com/@ByteofGeek).

The aim is to make it easier for you to follow along with my videos, explore how the automations work, and adapt them for your own Home Assistant setup.

## Available Automations

| Video / Collection | Description |
|---|---|
| [Zones Unleashed](zones-unleashed/) | Six example automations demonstrating how to use Home Assistant zones for location-based notifications, shopping reminders, commuting, gym tracking and heating control. |

More examples may be added as they're featured in future videos.

## Using These Automations

The YAML files are provided as examples of the configurations demonstrated in my videos.

Before using them:

1. Review the YAML and understand what the automation does.
2. Replace example entity IDs with those from your own Home Assistant installation.
3. Create any required zones, helpers or integrations described in the accompanying README.
4. Test the automation to ensure it behaves as expected.

These examples are intended as starting points rather than ready-to-use configurations for every Home Assistant installation.
